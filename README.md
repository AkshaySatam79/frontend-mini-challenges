# 🚀 Frontend Mini Challenges

A collection of small frontend projects built with **HTML, CSS, and Vanilla JavaScript** to practice core frontend development skills, strengthen JavaScript logic, and build real-world UI projects.

Each project focuses on a specific concept or functionality and is built from scratch without relying on frontend frameworks.

## 🎯 Purpose

This repository is my frontend development practice space where I build small projects to:

* Strengthen HTML and CSS fundamentals
* Improve JavaScript and DOM manipulation skills
* Practice problem-solving and logical thinking
* Learn how to build interactive user interfaces
* Practice responsive web design
* Work with browser APIs and events
* Improve Git and GitHub workflow
* Build projects that can be included in my developer portfolio

## 💰 Featured Project: Expense Tracker

The **Expense Tracker** is a dynamic frontend application for managing income and expenses.

### Features

* Add income and expense transactions
* Add transaction descriptions
* Enter transaction amounts
* Select transaction categories
* Automatically assign category icons
* Display transaction dates
* Calculate total income

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/AkshaySatam79/frontend-mini-challenges.git
```

Move into the project:

```bash
cd frontend-mini-challenges
```

Open any project folder and launch its `index.html` file in your browser.

For development, you can use **VS Code + Live Server**.

## 🔄 Development Workflow

For each new project, my workflow is:

1. Choose a small frontend challenge
2. Plan the UI and functionality
3. Build the structure with HTML
4. Style the interface with CSS
5. Add functionality using JavaScript
6. Test the project in the browser
7. Fix bugs and improve the UI
8. Commit the changes with Git
9. Push the project to GitHub
