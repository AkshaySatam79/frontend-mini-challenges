# Purrfect World 🐾

React + TypeScript + Tailwind + Framer Motion + Lucide cat discovery site.

## Run
    npm install
    npm run dev        # development
    npm run build      # type-check + production build (single-file dist/index.html)

## APIs
- The Cat API: images/search and breeds (uses the public demo key by default; set VITE_CAT_API_KEY to use a personal key)
- Cataas: /cat, /cat/cute/says/Meow, ?filter=mono
- catfact.ninja: /fact, /facts, and docs?api-docs.json
- http.cat/[status_code]

Favourites and theme are stored in localStorage.
